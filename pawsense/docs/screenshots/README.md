# Rendered beta previews

These images are generated by `tool/capture_visual_previews_test.dart` using
the production Flutter Canvas artwork and owner widgets. They are rendered
previews, not photographs or screenshots captured from a physical device.

- `prey-regular.png`: mouse, moth and fish movement and catch animation phases.
- `tablet-hunt-mouse.png`: actual medium target size on a 1024 × 768 board.
- `owner-home-phone.png`: the real owner home route with a local sample profile.

See `tool/VISUAL_PREVIEWS.md` to reproduce them and view the animation frames.
